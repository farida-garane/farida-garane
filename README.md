🙋 Qui suis-je
Je suis passionné·e par la création d'applications utiles, qui répondent à de vrais problèmes du quotidien. Ce que j'aime, c'est construire un projet en entier : penser l'architecture, développer l'API, créer l'interface, puis faire en sorte que tout fonctionne ensemble.
« Un bon logiciel, ce n'est pas celui qui a le plus de fonctionnalités, c'est celui qui résout vraiment un problème. »
Ce en quoi je crois :
•	Comprendre le besoin avant d'écrire la moindre ligne de code
•	Un code clair aujourd'hui, c'est du temps gagné demain
•	La technologie doit être adaptée aux réalités locales
